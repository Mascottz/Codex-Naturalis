Enter a name, a one-line claim, and a link to the work. The form composes a GitHub issue with the problem id and today's date.

This is a static site. The desk receives and stores no submission. The form opens GitHub; an attempt appears in the ledger only after its ledger pull request is reviewed and merged.

The verification ladder remains Attempted → Under review → Verified, or Withdrawn. Verification requires a published peer-reviewed result or a checked formal proof.
